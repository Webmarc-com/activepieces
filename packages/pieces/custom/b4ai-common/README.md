# B4AI Common

Shared utilities, authentication, and API client for B4AI custom pieces interacting with Surfsite API.

This package provides common functionality used by all B4AI pieces:
- Authentication handling
- HTTP client for Surfsite API
- Common models and types
- Shared constants

## Usage

This package is used as a dependency by other B4AI pieces:
- `@activepieces/piece-b4ai-knowledge`
- `@activepieces/piece-b4ai-graph`
- `@activepieces/piece-b4ai-core`
